# 벤치에서 반지까지

고교 벤치 멤버로 시작해 KBL과 NBA를 거쳐 MVP와 우승 반지에 도전하는 농구 커리어 시뮬레이션 게임이에요.

리그와 구단은 2026-27 시즌 기준 실제 명칭을 써요(`src/game/leagues.ts`). 비공식 팬 게임이고, 명칭의 권리는 각 권리자에게 있어요. 로고는 쓰지 않고, 실존 선수는 플레이 유형 예시, 은퇴 화면의 역대 기록 순위표(`src/game/records.ts`, 2025-26 시즌 종료 기준)와 닮은 꼴 선수(`src/game/comps.ts`)에만 나와요.

## 실행하기

Node.js 20.9 이상이 필요해요.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 열면 돼요.

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` / `npm start` | 프로덕션 빌드와 실행 |
| `npm test` | 게임 엔진 테스트 (커리어 300개를 은퇴까지 자동 플레이, 시즌 중 결정은 무작위) |
| `npm run balance` | 밸런스 리포트 (커리어 600개의 나이별 오버롤, NBA 진출률, MVP 비율) |
| `npm run typecheck` | 타입 검사 |
| `npm run lint` | 린트 |

## 구조

게임 규칙(엔진)과 화면(React)을 나눠 두었어요. 엔진은 React나 브라우저에 의존하지 않는 순수 TypeScript라서 테스트하기 쉽고, 나중에 서버에서 그대로 돌릴 수도 있어요.

## 게임 규칙 요약

- **능력치**: 슛, 볼 핸들링, 패스, 수비, BQ, 운동능력 여섯 가지예요. 리바운드는 따로 없고 키·윙스팬·운동능력·수비·BQ에서 나와요.
- **선수 생성**: 이름·등번호·국적·고등학교(또는 무작위)를 정하고 후보 셋 중 하나를 골라요. 후보는 모두 오버롤 45로 시작하고, 플레이 유형마다 주특기는 55, 강점은 50, 보조는 47, 나머지는 45까지 시작해요. 아주 드물게 가장 강한 능력치 하나만 5 더 높게 나와요. 키와 윙스팬도 유형에 맞춰 정해져요(예: 빅 가드 189–194cm). 오버롤은 포지션별 능력치 가중평균이에요.
- **성장**: 나이, 출전 시간, 활약, 훈련 초점, 숨겨진 특성(19세에 공개)이 영향을 줘요. 잠재력이 상한이고, 성인이 된 뒤 출전 시간이 적으면 잠재력이 깎여요.
- **진로**: 고교(3년) → 대학(NCAA 또는 U-리그) 또는 KBL 고졸 드래프트 → 프로. 프로 리그는 KBL, NBA G리그, 유로리그, NBA 순으로 수준이 높아요.
- **드래프트**: 신청하면 1순위부터 지명이 하나씩 불리는 진행 화면이 떠요. 스카우트 예상 범위에 들어서면 천천히, 내 이름이 불리기 직전에는 한 번 더 뜸을 들여요.
- **국가대표**: 올림픽, FIBA 농구 월드컵, 대륙컵(아시아컵·유로바스켓·아메리컵), 아시안게임이 실제 개최 주기대로 열려요.
- **키 성장**: 10대에 키가 갑자기 크면 포지션 전환 제안을 받아요.
- **시즌 투자**: 시즌 계획에서 보유 자금으로 두 가지까지 투자해요. 개인 스킬 코치(성장 +5%), 웨이트·피지컬(운동능력), 회복 관리팀(부상 위험 -20%, 건강), 영양·수면 관리(건강, 노화 완화), 영상 분석관(BQ, 코치 신뢰). 비용은 연봉에 비례하고, 학생 선수는 시즌마다 용돈·후원금 600만을 받아요.
- **시즌 진행**: 시즌 계획에서 훈련 초점과 투자를 고르고 시작하면, 프리시즌 → 정규시즌 한 경기씩 → 플레이오프(전국대회) 한 라운드씩 → 결산 순으로 저절로 흘러가요. 1배속이면 한 시즌이 30초 남짓이고, 일시정지·2배속·4배속·건너뛰기(결정이나 결승까지)가 있어요. 홈 탭에서 경기마다 상대·점수·내 기록과 시즌 평균이 쌓여요. 팀 승수와 부상은 시즌을 시작할 때 정해 두고 경기마다 나눠 보여줘서, 한 번에 계산하던 때와 밸런스가 같아요. 무소속·군 복무 시즌은 경기 대신 일정(훈련, D리그, 복무…)을 한 칸씩 지나요. 시즌 도중 저장해도 불러오면 멈춘 채로 이어져요.
- **체력과 부상**: 경기를 뛸 때마다 출전 시간만큼 건강이 닳아요(36분 에이스면 한 시즌에 NBA 약 51, KBL 약 41, 고교 약 30, 경기 사이 회복 전). 건강이 60 아래로 떨어지면 기록과 평점이 깎이고, 부상은 경기마다 그때 건강으로 굴려서 지칠수록 잘 다쳐요. 시즌이 끝나면 닳은 만큼의 절반쯤 돌아와서, 매년 오래 뛰는 주전은 건강 80대에서 시즌을 시작해요(`npm run balance`의 pro health 줄).
- **빅매치**: 정규시즌 중반과 막판 순위 싸움, 그리고 결승 직전에 출전을 강행할지 고르는 결정이 생겨요. 건강할수록 성공하기 쉽고, 성공하면 경기력이 오르고, 실패하면 다쳐서 다음 경기(결승이면 결승)에 나서지 못해요. 쉬면 건강을 회복하고 한 경기를 빠져요.
- **연봉 협상**: FA·이적·NBA 영입 제안을 고르면 바로 서명하지 않고 협상해요. 제시안 서명, 10% 인상 요구(거절되면 원래 조건), 25% 인상 요구(거절되면 구단이 떠나 다른 선택지로 돌아감), 계약 기간 1년 연장 요구 중에서 골라요. 성공 확률은 그 리그 수준 대비 오버롤, 지난 시즌 평점, 에이전시로 정해지고 숫자 대신 "협상력"으로 보여줘요. G리그 계약과 NBA 최저 연봉은 협상하지 않아요.
- **이적 요청**: 계약 기간 중에도 시즌 사이(오프시즌마다 한 번) 홈 탭의 계약 카드에서 이적을 요청할 수 있어요. 출전 시간이 적으면 구단이 쉽게 보내 주고, 팀의 핵심이거나 코치 신뢰가 높으면 붙잡아요. 허락되면 다른 구단 제안을 받고, 거절되면 코치 신뢰가 떨어지며 남은 연봉의 절반을 위약금으로 내고 FA가 될 수 있어요.
- **자금 쓰기**: 시즌 사이 홈 탭에서 한 번 사면 계속 남는 것을 사요. 맞춤 농구화(300만, 부상 위험 -5%), 부모님 집(3억), 드림카(4억), 내 집(5억, 시즌 뒤 건강 +4), 전담 셰프·영양팀(12억, 체력 소모 -12%), 개인 회복 센터(30억, 부상 위험 -15%·복귀 빠름), 개인 훈련장(60억, 성장 +4%·노화 -10%), 유소년 아카데미(150억, 은퇴 기록)가 있고, 유소년 농구 기부(1,000만~100억)는 은퇴 화면에 남아요.
- **시즌 중 이벤트**: 정규시즌 초중반과 후반에 한 번씩 50% 확률로 슬럼프, 라이벌 도발, 연전 피로, 스카우트 관전 같은 결정이 생겨 시즌이 잠시 멈춰요. 고른 결과는 남은 경기의 경기력(기록·평점)이나 결장 경기 수에 반영돼요. 오래 쉬어야 하는 부상(6경기 이상)을 당하면 서둘러 복귀할지, 완전히 회복할지 골라요.
- **생활 이벤트**: 오프시즌마다 45% 확률로 단계에 맞는 이벤트가 생겨요. 고교는 장기자랑·시험·수학여행, 대학은 학점·NIL 후원, 프로는 훈련 방식·에이전시·트레이너·SNS 논란 같은 일이에요. "도전" 선택지는 결과가 운에 달려 있어요. 대형 에이전시(연봉 제안 +10%)와 전담 트레이너(맡은 능력치 성장 +15%)는 커리어 내내 효과가 남아요.
- **은퇴**: 30세부터 직접 선언할 수 있고, 40세에는 은퇴해요. 프로 경력이 있는 선수는 명예의 전당에 올라가요. 은퇴하면 엔딩 전에 커리어 회고가 나와요. 도트 선수가 커리어 길을 따라 걸어가며 입단부터 시즌마다의 활약, 메달, 드래프트를 한 칸씩 보여주고 경기·득점·트로피가 쌓여 올라가요. 우승·MVP·금메달은 금색으로 빛나며 조금 더 오래 머물러요. 빠르게(3배속)와 엔딩 바로 보기가 있어요.
- **닮은 꼴 선수**: 은퇴 화면에서 내 프로 커리어와 가장 닮은 실제 KBL·NBA 선수를 하나씩, 비슷한 선수 둘과 함께 보여줘요. 포지션, 경기당 득점·리바운드·어시스트, 그 리그에서 뛴 시즌 수, MVP·우승 횟수, 커리어 위상(최고 오버롤)을 비교해요. 그 리그에서 뛰지 않았으면 프로 커리어 전체로 "KBL로 치면", "NBA로 치면"을 보여줘요. 실제 선수 값은 반올림한 대략적인 성향이라 화면에 숫자로 띄우지 않아요.
- **역대 기록 순위**: 은퇴 화면에서 NBA·KBL 정규리그 통산 득점·리바운드·어시스트와 올림픽 통산 득점을 실제 역대 순위표에 끼워 볼 수 있어요.
- **명예의 전당 순위**: NBA MVP 횟수 → 최고 오버롤 → 개인상 횟수 → 프로 통산 득점. 네 항목이 같으면 공동 순위예요.

밸런스를 바꾸려면 대부분 `src/game/leagues.ts`(리그 평균), `src/game/data.ts`(포지션 가중치와 키 범위), `src/game/ratings.ts`(나이별 성장량, 연봉), `src/game/season.ts`(성장·스탯·시상 공식)를 보면 돼요. 바꾼 뒤에는 `npm run balance`로 분포를 확인하세요.

### 육성 난이도 기준 (npm run balance, 무작위 선택 커리어 600개)

| 지표 | 값 |
| --- | --- |
