# 농구 선수 키우기

**벤치 뎁혀 반지 굽기**

고교 벤치 멤버로 시작해 KBL과 NBA를 거쳐 MVP와 우승 반지에 도전하는 농구 커리어 시뮬레이션 게임이에요. 은퇴한 선수는 온라인 랭킹에 올라가 다른 플레이어의 선수와 순위를 겨뤄요(https://www.bench2ring.com).

리그와 구단은 2026-27 시즌 기준 실제 명칭을 써요(`src/game/leagues.ts`). 비공식 팬 게임이고, 명칭과 로고의 권리는 각 권리자에게 있어요. 구단·학교 로고는 실제 로고 파일을 `public/logos/`에 넣으면 그대로 보여줘요(아래 "로고 넣기"). 로고 파일이 없는 팀은 이름과 대표색으로 만든 자체 엠블럼(`src/components/common/emblem.ts`)을 보여줘요. 엠블럼은 리그마다 바탕 모양이 다르고(NBA 원형, KBL 방패, G리그 육각형, 유로리그·U-리그 문장, NCAA 뾰족 방패, 고교 깃발), 가운데에는 SK·LG·셀틱·용산 같은 약칭이 들어가요. 실존 선수는 플레이 유형 예시, 은퇴 화면의 역대 기록 순위표(`src/game/records.ts`, 2025-26 시즌 종료 기준)와 닮은 꼴 선수(`src/game/comps.ts`)에만 나와요.

## 실행하기

Node.js 20.9 이상이 필요해요.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 열면 돼요.

게임은 DB 없이도 할 수 있어요. 은퇴 기록 등록과 랭킹 페이지(`/rankings`)를 쓰려면 Postgres 연결이 필요해요(아래 "온라인 랭킹").

1. `.env.example`을 `.env.local`로 복사하고 값을 채워요. 값은 커밋하지 않아요.
   - `DATABASE_URL`: 게임 서버용 Neon 연결 문자열 (Connection pooling을 켠 주소, 호스트에 `-pooler`)
   - `DATABASE_URL_UNPOOLED`: 마이그레이션용 연결 문자열 (pooling을 끈 주소)
   - `TOKEN_SECRET`: 플레이어 토큰 해시에 쓰는 비밀 값. `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`로 만들어요.
   - `RESEND_API_KEY`, `FEEDBACK_TO`: 의견 보내기 메일. [Resend](https://resend.com) API 키와 의견을 받을 주소예요. 도메인을 인증하기 전에는 Resend 가입 메일 주소로만 보낼 수 있어요. 비어 있으면 의견 보내기가 "지금은 의견을 보낼 수 없어요"로 끝나요.
2. `npm run db:migrate`로 테이블을 만들어요.

로컬은 Neon의 dev 브랜치, 배포는 main 브랜치 주소를 써요.

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` / `npm start` | 프로덕션 빌드와 실행 |
| `npm test` | 게임 엔진 테스트 (커리어 300개를 은퇴까지 자동 플레이, 시즌 중 결정은 무작위) |
| `npm run balance` | 밸런스 리포트 (커리어 600개의 나이별 오버롤, NBA 진출률, MVP 비율) |
| `npm run typecheck` | 타입 검사 |

| `npm run logos` | `logos-src/`의 원본 로고를 128×128 투명 PNG로 바꿔 팀과 연결하고, 로고가 없는 팀의 파일 이름을 리그별로 보여주기 (`dev`·`build` 전에는 요약만 보여주며 저절로 돌아요) |
| `npm run flags` | 국가대표 대회에 나오는 나라의 국기만 `flag-icons`에서 `public/flags/`로 복사하고 나라와 연결하기 (`dev`·`build` 전에 저절로 돌아요) |

## 로고 넣기

1. `npm run logos`를 실행하면 로고가 없는 팀의 정확한 파일 이름이 리그별(고교, U-리그, NCAA, KBL, G리그, 유로리그, NBA, 국가대표, 군 부대)로 나와요. 이 목록을 보며 로고를 준비해요.
2. 원본 로고를 `logos-src/`에 넣어요. 크기와 형식(PNG·JPG·WebP·SVG·GIF)은 상관없고, 파일 이름만 게임 속 이름과 똑같이 지어요. NBA 구단은 영문 팀 이름이 들어 있으면 그대로 넣어도 돼요(예: `boston_celtics_logo_primary.png` → 보스턴 셀틱스). 영문 이름 표는 `scripts/logos.mjs`의 `ALIASES`에 있어요.
   - 구단·학교: `src/game/leagues.ts`의 이름 그대로. 예: `보스턴 셀틱스.svg`, `서울 SK 나이츠.png`, `용산고.png`
   - 국가대표: 나라 이름. 예: `대한민국.png`
   - 군 부대: `상무 (국군체육부대).png`, `육군 (현역 복무).png`
3. `npm run dev`(또는 `npm run logos`)를 실행하면 원본을 **128×128 투명 PNG**로 바꿔 `public/logos/`에 게임 속 이름으로 저장해요. 흰 배경 위에 그려진 로고는 가장자리에 붙은 흰 배경을 지우고(로고 안쪽 흰색은 남겨요), 둘레 여백을 잘라내고, 비율을 지킨 채 가운데에 맞추고, 가장자리에 6px 여백을 둬요. 원본과 변환 스크립트가 바뀌지 않았으면 다시 변환하지 않아요. 이어서 `src/components/common/logos.generated.ts`를 다시 만들고, 연결된 로고 수와 이름이 맞지 않는 파일, 64px보다 작아 흐릴 수 있는 원본을 알려줘요.
4. 로고가 있는 팀은 선수 카드, 결정 선택지, 경기 기록, 드래프트, 결승 중계 등 엠블럼이 나오던 모든 곳에서 로고로 바뀌어요.

흰색이 아닌 배경(검정, 색 배경)은 지우지 않으니 배경이 투명한 PNG나 SVG 원본이 가장 깔끔해요. 어두운 테마와 파란 진행 팝업에서는 어두운 로고도 잘 보이게 밝은 타일 위에 올려 보여줘요. 이미 128×128로 준비한 파일은 `public/logos/`에 바로 넣어도 돼요(변환하지 않고 그대로 써요).

로고는 각 구단·리그·학교의 상표예요. 사용 허락을 받았거나 쓸 수 있는 파일을 넣어 주세요. 저장소에 올리지 않고 내 컴퓨터에서만 쓰려면 `.gitignore`에 `logos-src/*`, `public/logos/*`, `!logos-src/.gitkeep`, `!public/logos/.gitkeep`을 더하고, `logos.generated.ts`의 변경도 커밋하지 않으면 돼요.

## 국기

국가대표 대회의 대표팀은 둥근 국기로 보여줘요. 국기는 [flag-icons](https://github.com/lipis/flag-icons) 7.5.0(MIT, 라이선스는 `public/flags/LICENSE`)의 정사각형 SVG이고, 게임에 나오는 나라(`src/game/national.ts`의 대표팀과 대회 상대국)의 국기만 `public/flags/`에 복사해요. 상대국을 늘리면 `scripts/flags.mjs`의 `CODES`에 나라 이름과 국가 코드를 더하세요. 코드가 없는 나라는 `npm run flags`가 알려주고, 그동안은 엠블럼으로 보여줘요. 대만은 국제 대회에 차이니즈 타이베이 깃발로 나오는데 flag-icons에 그 깃발이 없어서 엠블럼(TPE)으로 보여줘요.

## 구조

게임 규칙(엔진)과 화면(React)을 나눠 두었어요. 엔진은 React나 브라우저에 의존하지 않는 순수 TypeScript라서 테스트하기 쉽고, 서버에서도 그대로 써요(기록 검사, 랭킹 점수).

## 게임 규칙 요약

- **능력치**: 슛, 볼 핸들링, 패스, 수비, BQ, 운동능력 여섯 가지예요. 리바운드는 따로 없고 키·윙스팬·운동능력·수비·BQ에서 나와요.
- **선수 생성**: 첫 화면에서 "커리어 시작하기"를 누르면 한 단계씩 진행해요. 캐릭터를 먼저 고르고, 포지션과 후보 셋 중 하나를 고른 뒤 이름·등번호·국적·고등학교(또는 무작위)를 정해요. 국적은 국가대표 대회가 있는 10개국 중에서 고르고(기본 대한민국), 나라마다 대표팀 전력과 발탁 기준 오버롤이 달라요. 병역 의무는 대한민국 선수만 져요. 후보는 모두 오버롤 45로 시작하고, 플레이 유형마다 주특기는 55, 강점은 50, 보조는 47, 나머지는 45까지 시작해요. 아주 드물게 가장 강한 능력치 하나만 5 더 높게 나와요. 키와 윙스팬도 유형에 맞춰 정해져요(예: 빅 가드 189–194cm). 오버롤은 포지션별 능력치 가중평균이에요.
- **히든 스탯**: 여러 능력치가 고르게 적당한 선수보다, 특정 능력치가 두드러진 선수를 더 높게 평가해요. 어떤 조합이 히든 스탯이 되는지, 조건이 무엇인지는 게임 안에서 보여주지 않아요. 조건을 처음 채우면 시즌 결산 소식으로 히든 스탯 이름과 함께 알려주고, 그때부터 능력치 패널에 나타나요. 히든 스탯은 출전 시간·계약 제안·드래프트·연봉·시상에 쓰이는 평가 오버롤을 올리고(화면의 오버롤은 그대로), 기록에도 작은 효과를 줘요. 개발용 조건과 수치는 `src/game/specialty.ts`에 있어요.
- **성장**: 나이, 출전 시간, 활약, 훈련 초점, 숨겨진 특성(19세에 공개)이 영향을 줘요. 잠재력이 상한이고, 성인이 된 뒤 출전 시간이 적으면 잠재력이 깎여요. 단, NCAA 선수는 벤치에 있어도 잠재력이 깎이지 않고, 강도 높은 팀 훈련 덕분에 프로에서 경기당 11분쯤 뛴 만큼은 커요.
- **진로**: 고교(3년) → 대학(NCAA 또는 U-리그) 또는 KBL 고졸 드래프트 → 프로. 리그 평균 오버롤은 고교 48, U-리그 58, KBL 68, NCAA 73, G리그 78, 유로리그 80, NBA 87이에요. 한국에서 NBA까지 가기가 그만큼 어려워요.
- **진출 기준**: 드래프트 지명, 계약 제안, NCAA 진학, NBA 영입 제안은 모두 그 리그 평균에서 얼마나 떨어져 있는지로 정해요. 예를 들어 NBA 정식 제안은 NBA 평균 이상, 최저 연봉 제안은 평균 - 3, NCAA 장학생은 NCAA 평균 - 8(그 아래 - 10까지 워크온)부터예요. 그래서 리그에 들어가면 제 몫의 출전 시간을 받지만, 들어가기가 어려워요. 리그 평균만 바꾸면 기준이 같이 움직여요(`src/game/decisions.ts`).
- **드래프트**: 신청하면 1순위부터 지명이 하나씩 불리는 진행 화면이 떠요. 스카우트 예상 범위에 들어서면 천천히, 내 이름이 불리기 직전에는 한 번 더 뜸을 들여요.
- **국가대표**: 올림픽, FIBA 농구 월드컵, 대륙컵(아시아컵·유로바스켓·아메리컵), 아시안게임이 실제 개최 주기대로 열려요. 올림픽은 강호만 바로 본선에 가고, 나머지는 최종예선(조별리그 약체 → 준결승 중위권 → 결승 상위권, 우승 1팀만 본선)을 거쳐요.
- **키 성장**: 10대에 키가 갑자기 크면 포지션 전환 제안을 받아요.
- **시즌 투자**: 시즌 계획에서 보유 자금으로 두 가지까지 투자해요. 개인 스킬 코치(성장 +5%), 웨이트·피지컬(운동능력), 회복 관리팀(부상 위험 -20%, 건강), 영양·수면 관리(건강, 노화 완화), 영상 분석관(BQ, 코치 신뢰). 비용은 연봉에 비례하고, 학생 선수는 시즌마다 용돈·후원금 600만을 받아요.
- **시즌 진행**: 시즌 계획에서 훈련 초점과 투자를 고르고 시작하면, 프리시즌 → 정규시즌 한 경기씩 → 플레이오프(전국대회) 한 라운드씩 → 결산 순으로 저절로 흘러가요. 1배속이면 한 시즌이 30초 남짓이고, 일시정지·2배속·4배속·건너뛰기(결정이나 결승까지)가 있어요. 홈 탭에서 경기마다 상대·점수·내 기록과 시즌 평균이 쌓여요. 팀 승수와 부상은 시즌을 시작할 때 정해 두고 경기마다 나눠 보여줘서, 한 번에 계산하던 때와 밸런스가 같아요. 무소속·군 복무 시즌은 경기 대신 일정(훈련, D리그, 복무…)을 한 칸씩 지나요. 시즌 도중 저장해도 불러오면 멈춘 채로 이어져요.
- **체력과 부상**: 경기를 뛸 때마다 출전 시간만큼 건강이 닳아요(36분 에이스면 한 시즌에 NBA 약 51, KBL 약 41, 고교 약 30, 경기 사이 회복 전). 건강이 60 아래로 떨어지면 기록과 평점이 깎이고, 부상은 경기마다 그때 건강으로 굴려서 지칠수록 잘 다치고 더 심하게 다쳐요. 건강 50 이상이면 길어야 시즌의 22%, 30~49면 30%쯤 빠지고, 시즌 절반 넘게 빠지는 시즌 아웃급 부상은 건강이 30 아래일 때만 나와요. 시즌이 끝나면 닳은 만큼의 절반쯤 돌아와서, 매년 오래 뛰는 주전은 건강 80대에서 시즌을 시작해요(`npm run balance`의 pro health 줄).
- **빅매치**: 정규시즌 중반과 막판 순위 싸움, 그리고 결승 직전에 출전을 강행할지 고르는 결정이 생겨요. 건강할수록 성공하기 쉽고, 성공하면 경기력이 오르고, 실패하면 다쳐서 다음 경기(결승이면 결승)에 나서지 못해요. 쉬면 건강을 회복하고 한 경기를 빠져요.
- **클러치**: 팀의 주전(예상 출전 26분) 이상이면 정규시즌 중 중요한 경기에서 마지막 플레이를 맡는 결정이 생겨요(시즌에 두 번, 각각 60% 확률). 공격 다섯(풀업 점퍼·돌파·패스·백도어 컷·풋백)과 수비 셋(에이스 수비·블록슛·차징 유도) 여덟 가지 중 무작위로 세 가지가 나와요. 어떤 능력치를 쓰는 플레이인지는 보여주지 않고, 고른 플레이의 능력치가 리그 평균보다 높을수록 성공하기 쉬워요. 성공하면 그 경기를 이기고 그 능력치가 +1, 경기력이 오르고, 실패하면 그 경기를 져요. 경기 기록에 '클러치' 표시가 남아요.
- **연봉 협상**: FA·이적·NBA 영입 제안을 고르면 바로 서명하지 않고 협상해요. 제시안 서명, 10% 인상 요구(거절되면 원래 조건), 25% 인상 요구(거절되면 구단이 떠나 다른 선택지로 돌아감), 계약 기간 1년 연장 요구 중에서 골라요. 성공 확률은 그 리그 수준 대비 오버롤, 지난 시즌 평점, 에이전시로 정해지고 숫자 대신 "협상력"으로 보여줘요. G리그 계약과 NBA 최저 연봉은 협상하지 않아요.
- **되묻기**: 이적·재계약·입단할 팀을 고르거나 위약금을 내고 계약을 해지할 때는 "정말 ~할까요?"로 한 번 더 물어요.
- **이적 요청**: 계약 기간 중에도 시즌 사이(오프시즌마다 한 번) 홈 탭의 계약 카드에서 이적을 요청할 수 있어요. 출전 시간이 적으면 구단이 쉽게 보내 주고, 팀의 핵심이거나 코치 신뢰가 높으면 붙잡아요. 허락되면 다른 구단 제안을 받고, 거절되면 코치 신뢰가 떨어지며 남은 연봉의 절반을 위약금으로 내고 FA가 될 수 있어요.
- **자금 쓰기**: 시즌 사이 홈 탭의 상점에서 보유 자금으로 물건을 사요. 상품은 30가지이고, 시즌마다 그중 6개(1억 미만·1억~20억·20억 넘게에서 두 개씩)가 진열돼요. 진열은 시즌이 바뀔 때마다 새로 정해지고, 이미 가진 상품은 다시 나오지 않아요. 상품은 장비(능력치 하나의 성장 +6% 등), 회복·생활(시즌 뒤 건강, 체력 소모, 부상 위험), 사치품(기분 전환), 일회성(진열될 때마다 다시 살 수 있는 가족 여행·전지훈련 등), 유산(재단·아카데미처럼 은퇴 기록에 남는 것)으로 나뉘어요. 상품마다 아이콘이 붙어요. 보유 중인 아이템과 효과는 같은 칸에서 언제든 볼 수 있어요. 유소년 농구 기부(1,000만·1억·10억·100억)는 금액마다 한 시즌에 한 번 할 수 있고, 20% 확률로 금액에 맞는 보답이 와요(1,000만: 건강 +5와 시즌 시작 경기력 상승, 1억: 무작위 능력치 1개 +1, 10억: 무작위 능력치 2개 +1과 시즌 시작 경기력 상승, 100억: 무작위 능력치 3개 +1과 건강 +10). 상품 목록은 `src/game/shop.ts`에 있어요.
- **시즌 중 이벤트**: 정규시즌 초중반과 후반에 한 번씩 50% 확률로 슬럼프, 라이벌 도발, 연전 피로, 스카우트 관전, 기자회견(대학·프로) 같은 결정이 생겨 시즌이 잠시 멈춰요. 고른 결과는 남은 경기의 경기력(기록·평점)이나 결장 경기 수에 반영돼요. 오래 쉬어야 하는 부상(6경기 이상)을 당하면 서둘러 복귀할지, 완전히 회복할지 골라요.
- **생활 이벤트**: 오프시즌마다 45% 확률로 단계에 맞는 이벤트가 생겨요. 고교는 장기자랑·시험·수학여행·체육대회 계주·사물함 편지, 대학은 학점·NIL 후원·해외 캠프·유니버시아드 선발전, 프로는 훈련 방식·에이전시·SNS 논란·주장 제안·시그니처 농구화·지인의 투자 권유 같은 일이에요(시즌 중 이벤트를 합쳐 63가지). "도전" 선택지는 결과가 운에 달려 있어요. 대형 에이전시(연봉 제안 +10%)와 전담 트레이너(맡은 능력치 성장 +15%)는 커리어 내내 효과가 남아요.
- **은퇴**: 30세부터 직접 선언할 수 있고, 40세에는 은퇴해요. 프로 경력이 있는 선수는 명예의 전당에 올라가요. 은퇴하면 엔딩 전에 커리어 회고가 나와요. 선수 캐릭터가 커리어 길을 따라 걸어가며 입단부터 시즌마다의 활약, 메달, 드래프트를 한 칸씩 보여주고 경기·득점·트로피가 쌓여 올라가요. 우승·MVP·금메달은 금색으로 빛나며 조금 더 오래 머물러요. 빠르게(3배속)와 엔딩 바로 보기가 있어요.
- **닮은 꼴 선수**: 은퇴 화면에서 내 프로 커리어와 가장 닮은 실제 KBL·NBA 선수를 하나씩, 비슷한 선수 둘과 함께 보여줘요. 포지션, 경기당 득점·리바운드·어시스트, 그 리그에서 뛴 시즌 수, MVP·우승 횟수, 커리어 위상(최고 오버롤)을 비교해요. 그 리그에서 뛰지 않았으면 프로 커리어 전체로 "KBL로 치면", "NBA로 치면"을 보여줘요. 실제 선수 값은 반올림한 대략적인 성향이라 화면에 숫자로 띄우지 않아요.
- **역대 기록 순위**: 은퇴 화면에서 NBA·KBL 정규리그 통산 득점·리바운드·어시스트와 올림픽 통산 득점을 실제 역대 순위표에 끼워 볼 수 있어요.
- **시즌 시상**: 리그마다 실제 상 이름으로 줘요(예: NBA MVP (마이클 조던 트로피), KBL 베스트5). 수상은 리그 평균 대비 평가 오버롤과 출전 시간으로 정한 영향력에 운을 더해 정해요. NBA 개인상은 기록 문턱도 넘어야 받아요(경기당 득점 / 득점+리바운드+어시스트): MVP·올-NBA 퍼스트팀 20 / 32, 세컨드팀 19 / 31, 서드팀·파이널 MVP·컨퍼런스 파이널 MVP 17 / 29, 올스타 15 / 26. 퍼스트팀 감이어도 기록이 모자라면 기록이 닿는 팀으로 내려가요. NBA에서 리그 평균 + 2보다 잘하는 선수는 공격을 더 맡아 득점이 1마다 6%(최대 30%) 늘어요. 수치는 `src/game/season.ts`에 있어요.
- **명예의 전당 순위**: 랭킹 점수 → NBA MVP 횟수 → 최고 오버롤 → 프로 통산 득점 순이에요. 랭킹 점수는 리그별 MVP·우승·파이널 MVP·개인상(NBA에서 받은 상일수록 커요), 국가대표 메달과 출전, 프로 통산 기록, 최고 오버롤, NBA 진출을 더한 값이에요(`src/game/hall.ts`). 온라인 랭킹도 같은 순서로 줄을 세워요.

밸런스를 바꾸려면 대부분 `src/game/leagues.ts`(리그 평균. 진출 기준과 연봉도 따라 움직여요), `src/game/data.ts`(포지션 가중치와 키 범위), `src/game/ratings.ts`(나이별 성장량, 연봉), `src/game/season.ts`(성장·스탯·시상 공식)를 보면 돼요. 바꾼 뒤에는 `npm run balance`로 분포를 확인하세요.

- 게임 이름을 "농구 선수 키우기 · 벤치 뎁혀 반지 굽기"로 정했어요. 한 장짜리 플레이 가이드와 설정(화면 테마, 리그별 구단 목록)을 더했어요.

## 저장

진행 내용은 브라우저 localStorage에 자동 저장돼요. 다른 기기로 옮기는 기능은 없어요. 은퇴한 선수의 전체 커리어는 엔딩을 다시 볼 수 있게 최근 20명까지 따로 보관해요(`b2r-endings-v1`). 은퇴한 선수의 요약만 온라인 랭킹 서버에 올라가요.

## 온라인 랭킹

은퇴 기록을 서버에 모아 전체·포지션별 순위, 역대 베스트 5, 스탯 랭킹을 보여줘요. 별도 서버 없이 Next.js Route Handler와 Postgres로 만들었어요. 설계와 단계별 계획은 [docs/online-leaderboard.md](docs/online-leaderboard.md)에 있어요.

- **DB**: [Neon](https://neon.tech) 서버리스 Postgres를 [Drizzle ORM](https://orm.drizzle.team)으로 써요. 서버는 쿼리마다 HTTP로 보내는 Neon 드라이버로 연결해서, 서버리스에서 연결이 쌓이지 않아요. Vercel 함수는 Neon과 같은 싱가포르 리전(`sin1`, `vercel.json`)에서 돌아요.
- **테이블** (`src/server/schema.ts`)
  - `players`: 익명 플레이어(기기). 브라우저가 토큰 원문을 갖고, DB에는 `TOKEN_SECRET`으로 만든 해시만 둬요.
  - `careers`: 제출한 은퇴 기록. 순위에 쓰는 값(랭킹 점수, NBA MVP, 최고 오버롤, 통산 기록 등)은 칸으로, 은퇴 요약 전체는 `summary`(jsonb)로 둬요. 플레이어마다 같은 커리어는 한 번만 받아요.
- **흐름**: 처음 기록을 올릴 때 익명 플레이어를 만들어 토큰을 localStorage(`b2r-player-v1`)에 둬요. 프로 무대를 밟고 은퇴하면 요약을 등록 대기열(`b2r-pending-v1`)에 넣고 보내요. 실패하면 다음에 접속할 때 다시 보내요. 서버가 안 되면 조용히 실패하고 게임은 오프라인으로 계속돼요. 선수를 만들 때 "은퇴하면 이름과 기록이 공개돼요"라고 알려요.
- **기록 검사** (`src/server/validate.ts`): 엔진이 낼 수 있는 모양과 범위인지(최고 오버롤, MVP 수와 수상 기록, 은퇴 나이, 레거시 등급 등) 봐요. 욕설이 들어간 선수 이름은 "익명의 선수"로 바꿔 올려요. 같은 플레이어는 1분에 한 번만 제출할 수 있어요. 기록을 서버에서 다시 돌려 보는 재생 검증은 아직 없어요(계획 2단계).
- **룰셋 버전**: 은퇴 기록에 그때의 밸런스 버전 `RULESET_VERSION`(`src/game/data.ts`)이 남아요. 지금은 2예요(NBA 시상 기록 문턱부터). 랭킹 화면과 순위 알림은 버전을 가리지 않고 모든 기록을 한 줄로 세우고, API는 `ruleset`으로 한 버전만 골라 볼 수 있어요.
- **캐시**: 순위표와 스탯 랭킹은 서버에서 캐시하고(`'use cache'` + `cacheTag("boards")`), 기록이 제출되면 바로 비워서 은퇴 직후에도 내 기록이 보여요.

| API | 하는 일 |
| --- | --- |
| `POST /api/players` | 익명 플레이어를 만들고 토큰을 돌려줘요 |
| `POST /api/careers` | 은퇴 기록 제출 (`Authorization: Bearer <토큰>`). 응답에 전체·포지션 순위를 담아요 |
| `GET /api/boards?scope=current\|all&pos=&day=YYYY-MM-DD` | 순위표: 전체 Top 100(포지션을 고르면 Top 50), 베스트 5, 전체 통계. `day`를 주면 그날(한국 시간) 올라온 기록끼리 매긴 순위예요 |
| `GET /api/stats?stat=pts\|reb\|ast\|stl\|blk\|tpm&day=YYYY-MM-DD` | 스탯 랭킹: 프로 통산 상위 50명. `day`는 순위표와 같아요 |
| `GET /api/careers/mine` | 내 토큰으로 올린 기록의 지금 순위 (랭킹 페이지 '나의 기록') |
