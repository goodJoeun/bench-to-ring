# 벤치에서 반지까지

고교 벤치 멤버로 시작해 KBL과 NBA를 거쳐 MVP와 우승 반지에 도전하는 농구 커리어 시뮬레이션 게임이에요.

리그와 구단은 2026-27 시즌 기준 실제 명칭을 써요(`src/game/data.ts`). 비공식 팬 게임이고, 명칭의 권리는 각 권리자에게 있어요. 로고와 실존 선수는 쓰지 않아요.

## 실행하기

Node.js 20.9 이상이 필요해요.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 열면 돼요.

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` / `npm start` | 프로덕션 빌드와 실행 |
| `npm test` | 게임 엔진 테스트 (커리어 300개를 은퇴까지 자동 플레이) |
| `npm run balance` | 밸런스 리포트 (커리어 600개의 나이별 오버롤, NBA 진출률, MVP 비율) |
| `npm run typecheck` | 타입 검사 |
| `npm run lint` | 린트 |

## 구조

게임 규칙(엔진)과 화면(React)을 나눠 두었어요. 엔진은 React나 브라우저에 의존하지 않는 순수 TypeScript라서 테스트하기 쉽고, 나중에 서버에서 그대로 돌릴 수도 있어요.

```
src/
├─ app/                 Next.js App Router (레이아웃, 페이지, 전역 스타일)
├─ components/          화면 컴포넌트
│  ├─ Game.tsx          화면 전환 (선수 생성 / 커리어 / 은퇴)
│  ├─ CreateScreen.tsx  선수 생성
│  ├─ GameScreen.tsx    커리어 진행 화면
│  ├─ ActionPanel.tsx   시즌 진행 버튼, 시즌 계획·오프시즌 결정 시트
│  ├─ Sheet.tsx         아래에서 올라오는 선택 시트
│  ├─ Toast.tsx         결정 결과 알림
│  ├─ SeasonLoading.tsx 시즌 진행 로딩 화면
│  ├─ Sprite.tsx        Canvas 도트 캐릭터
│  └─ tabs/             시즌 · 기록 · 트로피 · 명예의 전당 · 설정 탭
├─ lib/
│  └─ game-store.ts     화면과 엔진을 잇는 상태 저장소 (useSyncExternalStore)
└─ game/                게임 엔진 (순수 TypeScript)
   ├─ types.ts          모든 타입
   ├─ data.ts           포지션, 리그, 구단, 수상 같은 상수
   ├─ create.ts         후보 선수 생성, 커리어 시작
   ├─ season.ts         시즌 시뮬레이션, 성장, 부상, 시상, 국가대표
   ├─ offseason.ts      오프시즌 처리와 결정 대기열
   ├─ decisions.ts      진로·계약·이벤트 결정 만들기
   ├─ draft.ts          드래프트
   ├─ actions.ts        결정 선택 처리
   ├─ career.ts         은퇴, 커리어 요약, 레거시 등급
   ├─ hall.ts           명예의 전당 순위
   ├─ storage.ts        localStorage 저장, 저장 코드
   └─ random.ts         난수 (테스트용 시드 고정 지원)
```

## 게임 규칙 요약

- **선수 생성**: 후보는 모두 오버롤 45, 능력치 합 240으로 시작해요. 오버롤은 포지션별 능력치 가중평균이에요.
- **성장**: 나이, 출전 시간, 활약, 훈련 초점, 숨겨진 특성(19세에 공개)이 영향을 줘요. 잠재력이 상한이고, 성인이 된 뒤 출전 시간이 적으면 잠재력이 깎여요.
- **진로**: 고교(3년) → 대학(NCAA 또는 U-리그) 또는 KBL 고졸 드래프트 → 프로. 프로 리그는 KBL, NBA G리그, 유로리그, NBA 순으로 수준이 높아요.
- **국가대표**: 올림픽, FIBA 농구 월드컵, 대륙컵(아시아컵·유로바스켓·아메리컵), 아시안게임이 실제 개최 주기대로 열려요.
- **키 성장**: 10대에 키가 갑자기 크면 포지션 전환 제안을 받아요.
- **은퇴**: 30세부터 직접 선언할 수 있고, 40세에는 은퇴해요. 프로 경력이 있는 선수는 명예의 전당에 올라가요.
- **명예의 전당 순위**: NBA MVP 횟수 → 최고 오버롤 → 개인상 횟수 → 프로 통산 득점. 네 항목이 같으면 공동 순위예요.

밸런스를 바꾸려면 대부분 `src/game/data.ts`(리그 평균, 키 범위 등), `src/game/ratings.ts`(나이별 성장량, 연봉), `src/game/season.ts`(성장·스탯·시상 공식)를 보면 돼요. 바꾼 뒤에는 `npm run balance`로 분포를 확인하세요.

### 육성 난이도 기준 (npm run balance, 무작위 선택 커리어 600개)

| 지표 | 값 |
| --- | --- |
| 18세 시즌 후 오버롤 중앙값 | 59 |
| 22세 시즌 후 오버롤 중앙값 | 69 |
| 최고 오버롤 중앙값 / 상위 10% / 최고 | 73 / 84 / 91 |
| NBA 진출 비율 | 약 47% |
| NBA MVP 수상 비율 | 약 4% |

## 저장

진행 내용은 브라우저 localStorage에 자동 저장돼요. 설정 탭에서 저장 코드를 복사하거나 파일로 받아 다른 기기에서 불러올 수 있어요.

## 확장 아이디어

- 공유 랭킹: Route Handler와 데이터베이스를 붙여 은퇴 기록을 서버에 모으기

- 시즌 중 주요 경기 하이라이트, 라이벌 선수
- PWA로 오프라인 플레이
